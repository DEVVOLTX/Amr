# Security Policy

## Supported Versions
We actively support security updates for the latest version on the `main` branch.

| Version | Supported |
| :--- | :--- |
| main | ✅ |

## Reporting a Vulnerability

We take security seriously. If you find a vulnerability, please do NOT open a public issue.

Instead:
1. Go to the **Security** tab at the top of this repo
2. Click **Report a vulnerability**
3. Fill in the details

You can also contact me directly at GitHub @DEVVOITX

I will acknowledge your report within 48 hours and provide a fix timeline.

Thank you for helping keep the community safe!
